## 2. AI integration (10 integration points, 27 system prompts — the crown jewels)

- **Providers:** Google Gemini (`gemini-2.0-flash` family, key in Settings, 429 backoff) + **Ollama local LLM**
  (default `gemma3-27b-abliterated`, LAN URL `192.168.1.174:11434`, model discovery via `/api/tags`,
  `/ollama` proxy for remote CORS) with automatic cross-provider fallback.
- **`src/lib/prompts.ts` (771 lines):** 27 crafted prompt generators — combat advisor, spell explainer/tactician,
  quiz master, scene coach/generator/grader, improv grader, combat sim scenario + evaluator, character setup,
  persona builder, backstory helper + drills, dialogue suggestion/practice/evaluate/quick-draw/delivery coach,
  NPC conversation drill with per-turn voice-consistency coaching, interactive one-shot (DM + coach dual role),
  condition drill generator, accent phrase generator.
- **`characterContext()`** injects the *entire* character (stats, spells, slots, weapons, features, persona,
  backstory, race rules, homebrew, campaign) into every query. This is why the AI feels like it knows the character.

## 3. Live-table / remote access (the "open it every week" feature)

`game-night.bat` / `game-night.ps1` — one click: restart Ollama with CORS open → start dev server →
open Cloudflare quick tunnel → copy phone URL to clipboard. Full app + local AI on any phone, zero config.
`cloudflared.exe` ships in the repo. GitHub Pages deploy on push to `main` (`.github/workflows/deploy.yml`).

## 4. Data & persistence

localStorage, local-first, per-character keys: character roster + active id, AI config, training profile
(quiz history, SM-2 flashcard state, XP/streaks), combat state (survives reload), damage logs, session RP logs,
toybox, campaign, app mode. Legacy single-character migration on boot. JSON export/import for characters,
backstories, toybox.

## 5. Polish worth preserving

Dark-fantasy grimoire language: Cinzel Decorative / Alegreya / Cinzel, gold-on-ash palette
(gold `#c5a55a`, ember, arcane, eldritch, verdant), parchment cards with corner flourishes, ornate dividers,
drop caps on AI responses, animated `codex-ritual` border on the advisor, gold text selection.
Framer Motion staggers + page transitions, dice tumble animation, `prefers-reduced-motion` respected,
haptics hook on mobile, 44px touch targets, ARIA labels, WCAG AA contrast, safe-area insets.
