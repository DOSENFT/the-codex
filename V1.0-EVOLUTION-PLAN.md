# V1.0 EVOLUTION PLAN — the working ledger

**Trunk:** this repository. It never stops building, never stops running, never loses a capability.
**Metric for every slice:** *"If a real customer used yesterday's build and today's build side-by-side for an hour, which would they choose?"* If the answer isn't clearly "today's," the slice doesn't land.
**Prime law:** capability is never sacrificed for elegance. Baseline: `V0.9-CAPABILITY-BASELINE.md`.

**Direction (Marcus, 2026-07-19):** not a website, not a game — *spatial software*. Stay on React
(the trunk is already React 19 + Vite + Tailwind 4 + Motion — the "dream stack" is additive layers,
not a migration). Physicality where DMs spend their hours: writing, organizing, preparing, playing.
Every panel has depth; motion teaches; nothing pops; nothing teleports. Tauri packaging and
React Three Fiber enter as *additive slices on the working web core*, never as rewrites.

## Slice discipline
One slice = one shippable improvement, verified three ways before commit:
1. `npm run build` passes (types + bundle).
2. App boots and the touched surfaces work (dev server smoke test).
3. Capability check against the baseline: nothing removed, nothing degraded.
